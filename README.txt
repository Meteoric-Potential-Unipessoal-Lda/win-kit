win-kit 0.4 — набор мастера: диагностика и бережная чистка Windows 10/11
=========================================================================

КАК РАБОТАТЬ
1. Спросить клиента: на что жалуется (долго включается, тормозит, мало места,
   реклама, вылеты), для чего ПК, есть ли принтер/сканер, OneDrive/облако,
   игры, рабочий ли это компьютер.
2. AnyDesk -> скопировать папку win-kit на ПК клиента (например, на Рабочий стол).
3. Запустить start.bat. Он сам попросит права администратора.
   Если в AnyDesk чёрный экран — это окно «Разрешить изменения?»:
   либо клиент нажимает «Да», либо в AnyDesk «Действия -> Запросить повышение прав».
4. Откроется окно набора (тёмное, слева разделы):
   Обзор      — «Запустить диагностику»: карточки (Windows, процессор/память,
                диск, загрузка, антивирус, батарея), «Что найдено», «Что занимает место».
   План       — все пункты с галочками по разделам; кнопки «Как рекомендовано»,
                «+ всё можно», «Снять всё», поиск; внизу счётчик и «Выполнить».
   Выполнение — ход работы, журнал, итог; «Показать отчёт», «Перезапустить
                Проводник», «Перезагрузить ПК».
   Откат      — сеансы и изменения с галочками; «Отменить выбранное/весь сеанс».
   Отчёты     — архивы для Claude.
   Если окно не открылось — набор сам запустит консольное меню.
   Консольное меню без окна: start-console.bat.
   Меню консоли:
   1) Диагностика — только чтение, ничего не меняет. Отчёт в reports\.
   2) Оптимизация — диагностика -> план с галочками -> «y» -> точка
      восстановления + журнал -> изменения партиями по 5 с проверкой ->
      очистка мусора -> перезагрузка (по желанию).
   3) Откат — по журналу (весь сеанс или выборочно).
5. После перезагрузки (2–3 минуты после входа) — снова пункт 1:
   в отчёте будет таблица «было / стало».
6. Забрать архив из reports\ к себе (C:\cleanmytv\reports).

КОМАНДЫ В ПЛАНЕ
  3 5 7   — переключить галочки       3-7 — диапазон
  b       — отметить всё «можно»      n   — снять всё
  d       — вернуть как было          y   — ВЫПОЛНИТЬ      q — выйти

УРОВНИ
  авто            — отмечено сразу (мусор, проверено)
  можно           — безопасно, но польза небольшая (b — отметить всё)
  спросить клиента — решить вместе с клиентом
  Защищённое (антивирусы, драйверы, звук, тачпад, облака, VPN, банк,
  удалённый доступ и др.) в план не попадает вообще.

ЧТО ДЕЛАЕТ ВЕРСИЯ 0.2
  - Диагностика: Windows и активация, готовность к Windows 11, диски
    (SSD/HDD, износ, температура, ошибки), место, батарея, время загрузки
    и что её тормозит, синие экраны и сбои, процессы, автозагрузка, задачи,
    службы, обновления, драйверы с ошибками, Защитник и антивирусы,
    BitLocker, hosts/прокси, подозрительные задачи и автозапуск,
    программы удалённого доступа (частый след мошенников), лишние программы.
  - Оптимизация (обратимо, с журналом): автозагрузка (как в Диспетчере
    задач), задачи планировщика сторонних программ, службы сторонних
    программ -> «Вручную», схема питания «Экономия» -> «Сбалансированная».
  - Очистка (необратимо, но только мусор): временные файлы старше суток,
    кэш обновлений, отчёты об ошибках, дампы; по желанию — корзина,
    кэш браузеров, DISM, TRIM для SSD.

НОВОЕ В 0.3 (раздел плана -> что делает)
  Безопасность        — снимает запрет Защитника, поставленный политикой;
                        по слову клиента — выключает чужой прокси/PAC.
  Реклама и «советы»  — реклама в Пуске и на экране блокировки, тихая установка
                        Candy Crush и т.п., советы, рекламный ID, Bing в поиске,
                        виджеты, Copilot, Recall, телеметрия, фоновый Edge,
                        запись игр, расширения файлов, быстрый запуск
                        (всё через реестр, в журнал — откат возвращает как было).
  Приложения Магазина — удаление мусора (Candy Crush, Советы, Skype, Cortana…);
                        откат пробует вернуть сам (перерегистрация или winget),
                        иначе пишет ссылку на Магазин.
  Удаление программ   — CCleaner/IObit/«оптимизаторы», пробные McAfee/Norton,
                        чужие программы удалённого доступа (AnyDesk не трогается).
                        Только по галочке, НЕОБРАТИМО, окно удаления проходит мастер.
  Место               — гибернация (обратимо), Windows.old и файлы установки,
                        старые драйверы («Очистка диска» Windows), кэш Telegram.
                        «Что занимает место» и старые большие файлы в «Загрузках» —
                        только в отчёте (файлы пользователя набор не удаляет).
  Проверка            — быстрая проверка Защитником в конце.
  Диагностика         — расширения браузеров (не из магазина / поставленные
                        программой или политикой), подменённый поиск и стартовая
                        страница, ярлыки браузера с сайтом в параметрах.
  После настроек Пуска/поиска набор предложит перезапустить Проводник.
  Списки: data\tweaks.tsv (настройки), data\apps.tsv (приложения Магазина),
          data\startup.tsv, data\pup.tsv.

ВАЖНО
  - Журнал отката хранится на самом ПК: C:\ProgramData\CleanMyPC\backups
    (копия — в отчёте). Набор можно удалить с ПК — откат всё равно
    будет возможен, если снова принести набор.
  - Рабочий (доменный/корпоративный) ПК — только диагностика.
  - Прислать отчёт Claude: красные пункты, «ВНИМАНИЕ», синие экраны,
    ошибки набора (errors.txt), жалобы клиента после чистки.
  - Если в Защитнике или SmartScreen предупреждение на набор —
    прислать скриншот Claude, ничего не отключать.
